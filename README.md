# mapisometric

Mapa plano oscuro de El Salvador, en vista isométrica, con la flota de vehículos en 3D.

Incluye el mapa (calles, edificios y volcanes) y estas unidades:

- camión de carga
- ambulancia
- patrulla
- camión de personal
- autobús
- sedán y taxi
- rastra
- volqueta
- cisterna
- camión de bomberos
- excavadora y cargador CAT
- montacargas

## Correrlo

```bash
npm install
npm run dev
```

Abre http://127.0.0.1:8080
